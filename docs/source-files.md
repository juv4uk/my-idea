## English

The canonical file extension for **my-lisp** source code is **`.lisp`**. New examples, templates, and files created by my-idea should use names such as `welcome.lisp`, `radio.lisp`, or `fractions.lisp`.

The `.my` and `.wsm` extensions remain supported legacy aliases for existing or imported files. They are compatibility spellings, not the preferred extension. `.myl` is not part of the format contract.

my-idea detects the programming-language mode from a file name and shows the active mode in the bottom status bar. Users can also cycle the mode manually between my-lisp, ClojureScript, Rust, and plain text. Only my-lisp is currently executed by the embedded Language Lab; other runtimes will be connected explicitly in later milestones.

File extensions are not assigned by a universal registry. Future operating-system packages and editor integrations should associate `.lisp` with the my-lisp language identifier and a dedicated MIME type without claiming unrelated `.lisp` files automatically.
