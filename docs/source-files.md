# my-lisp source files · Файли my-lisp · my-lisp-Quelldateien

## English

The canonical file extension for **my-lisp** source code is **`.my`**. New examples, templates, and files created by my-idea should use names such as `welcome.my`, `radio.my`, or `fractions.my`.

The `.lisp` extension remains a compatible alias for existing or imported files. It is supported for convenience, but it is not the preferred extension of this language. `.myl` is not part of the format contract.

my-idea detects the programming-language mode from a file name and shows the active mode in the bottom status bar. Users can also cycle the mode manually between my-lisp, ClojureScript, Rust, and plain text. Only my-lisp is currently executed by the embedded Language Lab; other runtimes will be connected explicitly in later milestones.

File extensions are not assigned by a universal registry. Future operating-system packages and editor integrations should associate `.my` with the my-lisp language identifier and a dedicated MIME type without claiming unrelated `.my` files automatically.
