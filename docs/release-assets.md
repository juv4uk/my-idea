# Release asset names · Назви файлів релізу · Namen der Release-Dateien

## English

Installable and package-manager assets include the application version because downloaded files often leave the GitHub Release page. The name also identifies the target architecture or platform where needed. Examples: `my-idea_0.3.7_x64-setup.exe`, `my-idea_0.3.7_arm64-setup.exe`, and `my-idea_0.3.7_android.apk`.

Two assets are deliberately versionless: `my-idea-web.html` and `my-lisp-cli-web.html`. Both are portable single-file web entry points — the first the full IDE, the second a standalone browser REPL for the my-lisp CLI (see [`docs/quote-tutorial.md`](quote-tutorial.md) for what to try in it) — whose stable names are convenient for direct links and replacement. The Git tag and Release title remain the authoritative version context.

## Українська

Файли для встановлення та package managers містять версію програми, бо завантажені файли часто використовують поза сторінкою GitHub Release. За потреби назва також визначає цільову архітектуру або платформу. Приклади: `my-idea_0.3.7_x64-setup.exe`, `my-idea_0.3.7_arm64-setup.exe` і `my-idea_0.3.7_android.apk`.

Два навмисно безверсійні asset — `my-idea-web.html` і `my-lisp-cli-web.html`. Обидва є portable web entry point в одному файлі — перший це повний IDE, другий — окремий браузерний REPL для CLI my-lisp (див. [`docs/quote-tutorial.md`](quote-tutorial.md), що спробувати всередині) — стабільні назви яких зручні для прямих посилань і заміни. Git-тег та заголовок Release залишаються авторитетним контекстом версії.

## Deutsch

Installierbare Dateien und Paketmanager-Artefakte enthalten die Anwendungsversion, weil heruntergeladene Dateien häufig außerhalb der GitHub-Release-Seite verwendet werden. Der Name kennzeichnet bei Bedarf außerdem Zielarchitektur oder Plattform. Beispiele: `my-idea_0.3.7_x64-setup.exe`, `my-idea_0.3.7_arm64-setup.exe` und `my-idea_0.3.7_android.apk`.

Zwei Assets sind bewusst versionslos: `my-idea-web.html` und `my-lisp-cli-web.html`. Beide sind portable Web-Einstiegspunkte in einer Datei — der erste die vollständige IDE, der zweite ein eigenständiger Browser-REPL für die my-lisp-CLI (siehe [`docs/quote-tutorial.md`](quote-tutorial.md) für Beispiele) — deren stabile Namen für direkte Links und Ersetzungen praktisch sind. Git-Tag und Release-Titel bleiben der maßgebliche Versionskontext.
