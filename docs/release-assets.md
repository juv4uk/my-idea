# Release asset names · Назви файлів релізу · Namen der Release-Dateien

## English

Installable and package-manager assets include the application version because downloaded files often leave the GitHub Release page. The name also identifies the target architecture or platform where needed. Examples: `my-idea_0.3.7_x64-setup.exe`, `my-idea_0.3.7_arm64-setup.exe`, and `my-idea_0.3.7_android.apk`.

One asset is deliberately versionless: `my-idea-web.html`, a portable single-file web entry point for the full IDE, whose stable name is convenient for direct links and replacement. The Git tag and Release title remain the authoritative version context.

`my-lisp` moved to its own repository ([github.com/juv4uk/my-lisp](https://github.com/juv4uk/my-lisp)) and now ships its own standalone browser REPL, `my-lisp-cli-web.html`, from [that repo's releases](https://github.com/juv4uk/my-lisp/releases/latest) — see [`docs/quote-tutorial.md`](quote-tutorial.md) for what to try in it. `my-idea` no longer builds or publishes it.

## Українська

Файли для встановлення та package managers містять версію програми, бо завантажені файли часто використовують поза сторінкою GitHub Release. За потреби назва також визначає цільову архітектуру або платформу. Приклади: `my-idea_0.3.7_x64-setup.exe`, `my-idea_0.3.7_arm64-setup.exe` і `my-idea_0.3.7_android.apk`.

Один навмисно безверсійний asset — `my-idea-web.html`, portable web entry point в одному файлі для повного IDE, стабільна назва якого зручна для прямих посилань і заміни. Git-тег та заголовок Release залишаються авторитетним контекстом версії.

`my-lisp` переїхав у власний репозиторій ([github.com/juv4uk/my-lisp](https://github.com/juv4uk/my-lisp)) і тепер публікує власний окремий браузерний REPL, `my-lisp-cli-web.html`, [зі своїх релізів](https://github.com/juv4uk/my-lisp/releases/latest) — див. [`docs/quote-tutorial.md`](quote-tutorial.md), що спробувати всередині. `my-idea` більше не збирає й не публікує його.

## Deutsch

Installierbare Dateien und Paketmanager-Artefakte enthalten die Anwendungsversion, weil heruntergeladene Dateien häufig außerhalb der GitHub-Release-Seite verwendet werden. Der Name kennzeichnet bei Bedarf außerdem Zielarchitektur oder Plattform. Beispiele: `my-idea_0.3.7_x64-setup.exe`, `my-idea_0.3.7_arm64-setup.exe` und `my-idea_0.3.7_android.apk`.

Ein Asset ist bewusst versionslos: `my-idea-web.html`, ein portabler Web-Einstiegspunkt in einer Datei für die vollständige IDE, dessen stabiler Name für direkte Links und Ersetzungen praktisch ist. Git-Tag und Release-Titel bleiben der maßgebliche Versionskontext.

`my-lisp` ist in ein eigenes Repository umgezogen ([github.com/juv4uk/my-lisp](https://github.com/juv4uk/my-lisp)) und veröffentlicht seinen eigenständigen Browser-REPL, `my-lisp-cli-web.html`, nun aus [dessen eigenen Releases](https://github.com/juv4uk/my-lisp/releases/latest) — siehe [`docs/quote-tutorial.md`](quote-tutorial.md) für Beispiele. `my-idea` baut und veröffentlicht ihn nicht mehr.
