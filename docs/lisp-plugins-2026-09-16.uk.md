# Плагіни на my-lisp: наш власний Emacs

my-idea можна розширювати й налаштовувати, пишучи справжній my-lisp — так
само, як Emacs розширюється Emacs Lisp, а не C. Хост (Rust/Tauri) дає лише
механізм: реєстрацію команд, прив'язку клавіш, підписку на події, читання
буфера/виділення та застосування ефекту. Що саме робить команда чи
обробник — вирішує сам Lisp-плагін.

Це не нова експериментальна фіча — механізм (issues #7/#9/#10/#11:
`IDE-LISP-API-1`, `IDE-LISP-PLUGINS-1`, `IDE-LISP-HOOKS-1`) існував у коді
й був повністю покритий тестами й раніше, але жодного разу не був
підключений до реального застосунку: `EditorCommandRegistry` ніколи не
встановлювався в живу сесію, кнопок у UI не було. Ця версія вперше робить
його реально доступним.

## Де живуть плагіни

- `~/.config/my-idea/init.lisp` — завантажується першим, якщо існує.
- `~/.config/my-idea/plugins/*.lisp` — завантажуються по черзі за
  алфавітом імені файлу, кожен ізольовано (один зламаний плагін не заважає
  решті завантажитись).

Перезавантаження — явне: кнопка "⟲" у шапці my-idea. Жодного
файл-вотчера — так само, як `M-x eval-buffer`/`load-file` в Emacs.

## Editor API

- `(editor/register-command "ім'я" (lambda () ...) "опис")` — реєструє
  команду.
- `(editor/keymap "Ctrl-Shift-b" "ім'я-команди")` — прив'язує клавішу.
  Формат рядка — рідний формат CodeMirror (`"Ctrl-s"`, `"Mod-p"`, `"F9"`),
  бо саме CodeMirror вирішує, які фізичні клавіші перехоплювати; сам хост
  ніяк цей рядок не інтерпретує.
- `(editor/on "подія" "ідентифікатор-обробника" (lambda () ...))` —
  підписується на подію. Наразі my-idea реально шле: `"after-open"`
  (файл щойно відкрито), `"before-save"` / `"after-save"`.
- `(editor/buffer-text)` / `(editor/selection)` — читають поточний буфер і
  виділення.
- `(editor/replace-selection "текст")` — замінює виділення.
- `(editor/message "текст")` — показує повідомлення в REPL-консолі.

Неавторизовані host-можливості (файли, процеси) звідси недоступні — жодна
`read-file`-подібна capability не реєструється разом з Editor API.

## Приклад

Повний робочий приклад — `docs/examples/plugins/hello.lisp` (він же й
регресійний тест: `src-tauri/tests/example_plugin_contract.rs` гарантує,
що приклад не застаріє й далі реально завантажується). Скопіюй його в
`~/.config/my-idea/plugins/` і натисни "⟲".

## Виклик команд без клавіші — "M-x"

Кнопка "⌘ Команди" в шапці my-idea (дух Emacs' `M-x`) відкриває список
зареєстрованих команд і викликає обрану за назвою — без потреби мати
клавішу.

## Відома межа

Нова прив'язка клавіші, додана через `editor/keymap` після
перезавантаження плагінів, застосовується до вже відкритого редактора
лише після повторного монтування (перемикання вкладки чи повторне
відкриття файлу) — CodeMirror не тримає keymap реактивним. Команди й хуки
(`editor/on`) працюють одразу, без цього обмеження.
