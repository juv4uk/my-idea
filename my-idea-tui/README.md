# my-idea-tui

Термінальна (TUI) поверхня **my-idea** на **Ratatui** — *той самий продукт*, що GUI,
лише в терміналі. Це **не** новий рушій, **не** друга мова і **не** другий продукт.

Відповідає задачі [#31](https://github.com/juv4uk/my-idea/issues/31) і результату
дослідження [#84](https://github.com/juv4uk/my-idea/issues/84). Продуктова межа —
`docs/ADR-003-SIMPLE-SELF-BUILDING-IDE.md`.

> **Стан на 19.10.2026:** [GitHub Actions #39308425719](https://github.com/juv4uk/my-idea/actions/runs/39308425719) успішно зібрав TUI й pinned SENS CLI, виконав тести та реальні file-mode / український REPL / REPL meta-команду. У TUI є AST (F6) та вкладки.
> Це **підтверджена перша робоча вертикаль**, а не завершений паритет GUI↔TUI. Загальна готовність IDE відстежується в [#77](https://github.com/juv4uk/my-idea/issues/77), а native Run/Check — в [#78](https://github.com/juv4uk/my-idea/issues/78).

## Перша вертикаль (#31)

`Open workspace → Explorer → Edit → Save → Run → Output → Stop`

- **Explorer** — дерево/список файлів робочого каталогу, активний файл.
- **Editor** — відкриті вкладки з окремими Unicode-буферами й Undo/Redo: відкрити → редагувати → перемкнутися → зберегти через спільний із GUI workspace-save механізм.
- **Console/Output** — введення, історія (↑/↓), прокрутка; вивід рушія з точним
  походженням **stdout / stderr / system**.
- **Run** — запускає збережений файл через `sens <file>` або сумісний `my-lisp <file>`, не stdin REPL; **Stop** — реальна зупинка процесу.

## Семантика й піни

- Єдине джерело — **поточний pinned `external/sens`**. TUI лише запускає той самий
  `my-lisp` CLI, який збирається з цього gitlink (як і GUI-консоль).
- **Gitlink `external/sens` не змінюється** для додавання TUI; #81 — окрема задача.
- **Жодного власного Lisp-інтерпретатора** в TUI. Жодної другої семантики.
- Старі згадки `my-lisp`/legacy — не нормативна підстава повертати стару семантику.

## Залежності

```toml
ratatui   = { version = "0.30", default-features = false, features = ["crossterm"] }
crossterm = "0.29"
```

Один термінальний бекенд, без зайвих шарів. Рушій **не** додається як Cargo-залежність.

## Збірка й запуск

```sh
# 1) ініціалізувати саме закріплений підмодуль:
git submodule update --init external/sens
# 2) зібрати CLI з поточного exact gitlink:
cargo build --release --manifest-path external/sens/Cargo.toml -p sens-cli --bin my-lisp
# 3) окремо зібрати TUI (не чіпає кореневий lockfile):
cargo build --release --manifest-path my-idea-tui/Cargo.toml
# 4) запустити з будь-якого поточного каталогу:
./my-idea-tui/target/release/my-idea-tui
# або відкрити конкретний workspace, не змінюючи поточного каталогу:
./my-idea-tui/target/release/my-idea-tui /шлях/до/проєкту
```

Якщо CLI не зібрано в `external/sens/target/{release,debug}`, консоль показує інформативну помилку. `PATH` та `MY_LISP_BIN` не підміняють pinned джерело. Шлях до вже зібраного бінарника сам собою не є SHA-attestation: після зміни gitlink перебудуйте CLI.

## Клавіші

| Клавіша | Дія |
|---|---|
| `Tab` / `Shift-Tab` | перемикання панелей |
| `Enter` | Explorer: відкрити; Console: надіслати; Editor: новий рядок |
| `↑` / `↓` | Explorer: вибір; Console: історія команд зі збереженням чернетки й UTF-8 курсора |
| `PageUp` / `PageDown` / `End` | Console: попередній вивід / наступний / найновіший |
| Bracketed paste із буфера термінала | Editor: багаторядковий UTF-8 одним блоком; Console: тільки один рядок, без випадкового виконання кількох форм |
| `F5` | Запуск збереженого файла через pinned SENS CLI |
| `F6` | показати/сховати AST від **того самого pinned SENS reader** (синтаксичні помилки з рядком і стовпцем) |
| `Alt+PageUp` / `Alt+PageDown` | прокручувати AST при відкритій панелі |
| `Backspace` (Explorer) | до батьківського каталогу в межах workspace |
| `F9` | Stop (файл і REPL) |
| `Ctrl-S` | зберегти поточну вкладку |
| `Ctrl-Tab` / `Ctrl-Shift-Tab` | наступна / попередня вкладка; незбережені зміни не втрачаються |
| `Ctrl-W` | закрити поточну вкладку, якщо в ній немає незбережених змін |
| `Ctrl-Z` / `Ctrl-Y` | скасувати / повторити редагування; після відкриття іншого файла історія очищається |
| `Delete` | видалити символ праворуч від курсора, без пошкодження UTF-8 |
| `Ctrl-C` / `Ctrl-Q` | вихід (при незбережених змінах потрібно повторити) |
| `Esc` | повернутися до Explorer |

Мета-команди консолі: `:інтерфейс uk|de|en` змінює тільки локалізацію Ratatui; `:run`, `:stop`, `:save` — локальні команди IDE. **Решта команд із двокрапкою**, зокрема `:мова`, `:допомога`, `:імена`, `:ім’я`, передаються безпосередньо справжньому SENS REPL.

## Мова інтерфейсу

`uk → de → en` — за чинними ключами GUI (`src-cljs/my_idea/i18n.cljs`).
Мова інтерфейсу **не** є перемикачем доменної/семантичної SENS-проєкції.

## Що далі (поза першою вертикалею)

AST-панель (F6) використовує справжній `sens::parse` із pinned gitlink; вкладки з окремими буферами вже реалізовані. Палітра команд і повний GUI↔TUI паритет ще попереду. Візуальні компоненти ClojureScript і Ratatui **окремі**; повторно використовуються контракт команд і семантика виконання, а не віджети.

## Точне виконання

- F5 не надсилає файл у REPL. Перед запуском незбережені зміни треба зберегти через Ctrl+S.
- Текстовий `.lisp` читається редактором; фізичний `.sens` залишається бінарним артефактом і не відображається як UTF-8 Lisp.
- Інтерактивний REPL запускається окремо при першій введеній команді. Run показує stdout/stderr та код завершення CLI у консолі.
- [GitHub Actions #39308425719](https://github.com/juv4uk/my-idea/actions/runs/39308425719) підтвердив 29/29 тестів Ratatui та 3/3 реальних pinned SENS smoke (file-mode з результатом, синтаксична помилка, UKR REPL і мета-команда). Перевірка звіряє точний gitlink перед збиранням CLI. Це **не** підтверджує всі сценарії повного IDE або інтерактивний ручний огляд.

## Окремі мови IDE і SENS

TUI запускає інтерактивний REPL із явним `--surface=укр` (повна українська SENS-проєкція). `:інтерфейс uk|de|en` змінює тільки підписи інтерфейсу, а `:мова укр|ук|en|sa|core` передається реальному SENS. Промпт `SENS>` не ототожнює мову IDE із семантикою. Файловий F5 лишається окремим CLI file-mode; його актуальну працездатність підтверджує smoke конкретного перевіреного SHA, а зміна gitlink потребує нової перевірки.
